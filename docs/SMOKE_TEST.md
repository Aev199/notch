# Ручная проверка на Windows

1. Запустить `notch.exe` из обычной папки (например, `Загрузки\Notch`). Вверху по центру должна появиться маленькая чёрная капсула, рядом с exe — `notch.settings.json` (после первого сохранения настроек) и папка `cache\shelf`.
2. Клик по рабочему столу и окнам под прозрачной частью сцены (540×280 вокруг капсулы) проходит насквозь.
3. Навести курсор на капсулу: она раскрывается сразу, без паузы. Увести курсор: через ~0,3 с сворачивается.
4. Alt+Tab: Notch в списке нет. На панели задач тоже нет, иконка есть только в трее.
5. Открыть Блокнот и печатать. Навести курсор на чёлку и покликать вкладки: курсор ввода в Блокноте не теряется.
6. Win+Shift+S → выделить область: на капсуле мигает счётчик полки, во вкладке «Полка» появляется миниатюра.
7. Перетащить миниатюру в Telegram / браузер / папку Проводника: файл PNG принимается. Пока тянете, чёлка не сворачивается.
8. Кнопка «Копировать» на карточке → Ctrl+V в Paint: вставляется та же картинка, новая карточка на полке не появляется.
9. Скопировать несколько строк текста: они появляются во вкладке «Буфер», повторы не дублируются. Клик по строке → Ctrl+V вставляет её, чёлка свернулась.
10. Выделить русский текст и быстро нажать Ctrl+C дважды: чёлка открывается на вкладке «Перевод» с английским переводом. С английским текстом то же, перевод на русский.
11. Скопировать текст, нажать Ctrl+Alt+T: открывается перевод скопированного текста, каретка стоит в поле ввода, текст выделен — можно сразу печатать новый.
12. Кликнуть в поле перевода и напечатать текст: ввод работает, перевод обновляется. Esc: чёлка сворачивается, фокус возвращается в предыдущее окно.
13. Отключить сеть (или просто без интернета): перевод RU→EN и EN→RU работает, в заголовке написано «офлайн». Первый перевод после запуска может занять 1–2 с.
14. Включить «Запускать вместе с Windows», в `regedit` проверить значение `Notch` в `HKCU\...\Run`. Выключить: значение удалено.
15. Запустить полноэкранное видео (YouTube, F) или браузер по F11: вместо капсулы тонкая полоса, вкладки и элементы под ней нажимаются. Задержать курсор у самого верхнего края: чёлка открывается. Игра в эксклюзивном полноэкранном режиме: чёлки не видно вовсе.
16. Запустить второй `notch.exe`: вторая копия сразу закрывается.
17. Скопировать пароль из KeePass / Bitwarden: во вкладку «Буфер» он не попадает.
18. Сменить масштаб экрана (125% → 150%): капсула остаётся по центру сверху, наведение срабатывает точно по ней.
19. Ничего не делать 4 секунды: капсула сжимается в тонкую полосу. Скопировать текст: появляется капсула с подсвеченным счётчиком, потом снова полоса.
20. Открыть чёлку, быстро кликать по вкладкам, кнопкам «Копировать», «Удалить», шестерёнке (20–30 раз): каждое нажатие срабатывает.
21. В середине капсулы больше нет «камеры» (кружка).
22. На полке больше 8 скриншотов (по умолчанию хранится 30). Если в `notch.settings.json` осталось старое значение 8, поменять в настройках «Скриншотов на полке». Колесо мыши прокручивает сетку вниз-вверх плавно.
23. Перетащить скриншот на другой: появляется подсказка «в группу», после отпускания появляется карточка-стопка со счётчиком. Перетащить ещё один на стопку: счётчик растёт.
24. Клик по стопке открывает группу. «‹ Полка» возвращает назад. Перетащить скриншот из группы на «Вынуть из группы» (или нажать кнопку на карточке): он снова лежит отдельно.
25. Перетащить стопку (или «Тащить все» внутри группы) за край чёлки в папку Проводника: копируются все файлы группы. Отдельный скриншот вытаскивается так же, просто за край чёлки.
26. «Очистить» на полке удаляет только скриншоты вне групп. Группы переживают перезапуск программы.
27. Курсор в Блокноте → навести на чёлку → «Буфер» → «Вставить» у любой строки: текст вставлен в Блокнот, чёлка свернулась. То же в браузере, Word, Telegram.
28. Напечатать текст в поле перевода → кнопка «Вставить перевод»: перевод вставлен в окно, где вы работали до этого.
29. Клик по скриншоту на полке: открывается крупный просмотр, «‹ Полка» или Esc возвращает назад. Картинку из просмотра можно вытащить за край чёлки.
30. В просмотре «Текст»: справа появляется распознанный текст (русский и английский). Кнопки «Копировать» и «Вставить» работают. Если язык распознавания не установлен в Windows, видна понятная ошибка.
31. В просмотре «Перевести»: открывается вкладка «Перевод» с распознанным текстом и переводом.
32. «Буфер» → клик в «Поиск», набрать часть слова: список фильтруется; Enter вставляет первую найденную строку в окно, где был курсор. Esc очищает поиск, второй Esc сворачивает чёлку.
33. Закрепить строку (значок булавки): она поднимается наверх с синей булавкой, не пропадает при «Очистить» и после перезапуска программы (`notch.pins.json` рядом с exe).
