# Ручная проверка на Windows

1. Запустить `notch.exe` из обычной папки (например, `Загрузки\Notch`). Вверху по центру должна появиться маленькая чёрная капсула, рядом с exe — `notch.settings.json` (после первого сохранения настроек) и папка `cache\shelf`.
2. Клик по рабочему столу и окнам под прозрачной частью сцены (540×280 вокруг капсулы) проходит насквозь.
3. Навести курсор на капсулу: она раскрывается сразу, без паузы. Увести курсор: через ~0,3 с сворачивается.
4. Alt+Tab: Notch в списке нет. На панели задач тоже нет, иконка есть только в трее.
5. Открыть Блокнот и печатать. Навести курсор на чёлку и покликать вкладки: курсор ввода в Блокноте не теряется.
6. Win+Shift+S → выделить область: на капсуле мигает счётчик полки, во вкладке «Полка» появляется миниатюра.
7. Перетащить миниатюру в Telegram / браузер / папку Проводника: файл PNG принимается. Пока тянете, чёлка не сворачивается.
8. Кнопка «Копировать» на карточке → Ctrl+V в Paint: вставляется та же картинка, новая карточка на полке не появляется.
9. Скопировать несколько строк текста: они появляются во вкладке «Буфер», повторы не дублируются. Клик по строке → Ctrl+V вставляет её, чёлка свернулась.
10. Выделить русский текст и быстро нажать Ctrl+C дважды: чёлка открывается на вкладке «Перевод» с английским переводом. С английским текстом то же, перевод на русский.
11. Скопировать текст, нажать Ctrl+Alt+T: открывается перевод скопированного текста, каретка стоит в поле ввода, текст выделен — можно сразу печатать новый.
12. Кликнуть в поле перевода и напечатать текст: ввод работает, перевод обновляется. Esc: чёлка сворачивается, фокус возвращается в предыдущее окно.
13. Отключить сеть (или просто без интернета): перевод RU→EN и EN→RU работает, в заголовке написано «офлайн». Первый перевод после запуска может занять 1–2 с.
14. Включить «Запускать вместе с Windows», в `regedit` проверить значение `Notch` в `HKCU\...\Run`. Выключить: значение удалено.
15. Запустить полноэкранное видео (YouTube, F) или браузер по F11: вместо капсулы тонкая полоса, вкладки и элементы под ней нажимаются. Задержать курсор у самого верхнего края: чёлка открывается. Игра в эксклюзивном полноэкранном режиме: чёлки не видно вовсе.
16. Запустить второй `notch.exe`: вторая копия сразу закрывается.
17. Скопировать пароль из KeePass / Bitwarden: во вкладку «Буфер» он не попадает.
18. Сменить масштаб экрана (125% → 150%): капсула остаётся по центру сверху, наведение срабатывает точно по ней.
19. Ничего не делать 4 секунды: капсула сжимается в тонкую полосу. Скопировать текст: появляется капсула с подсвеченным счётчиком, потом снова полоса.
20. Открыть чёлку, быстро кликать по вкладкам, кнопкам «Копировать», «Удалить», шестерёнке (20–30 раз): каждое нажатие срабатывает.
21. В середине капсулы больше нет «камеры» (кружка).
22. На полке больше 8 скриншотов (по умолчанию хранится 30). Если в `notch.settings.json` осталось старое значение 8, поменять в настройках «Скриншотов на полке». Колесо мыши прокручивает сетку вниз-вверх плавно.
23. Перетащить скриншот на другой: появляется подсказка «в группу», после отпускания появляется карточка-стопка со счётчиком. Перетащить ещё один на стопку: счётчик растёт.
24. Клик по стопке открывает группу. «‹ Полка» возвращает назад. Перетащить скриншот из группы на «Вынуть из группы» (или нажать кнопку на карточке): он снова лежит отдельно.
25. Перетащить стопку (или «Тащить все» внутри группы) за край чёлки в папку Проводника: копируются все файлы группы. Отдельный скриншот вытаскивается так же, просто за край чёлки.
26. «Очистить» на полке удаляет только скриншоты вне групп. Группы переживают перезапуск программы.
27. Курсор в Блокноте → навести на чёлку → «Буфер» → «Вставить» у любой строки: текст вставлен в Блокнот, чёлка свернулась. То же в браузере, Word, Telegram.
28. Напечатать текст в поле перевода → кнопка «Вставить перевод»: перевод вставлен в окно, где вы работали до этого.
29. Клик по скриншоту на полке сразу открывает редактор (без промежуточного просмотра). Перетаскивание карточки на другую по-прежнему собирает группу, за край чёлки — выносит файл.
30. В редакторе «Текст»: справа панель с распознанным текстом (русский и английский). Если задана обрезка, читается только она; после смены рамки появляется «Распознать заново». Текст можно поправить, «Копировать» кладёт его в буфер. Если язык распознавания не установлен в Windows, видна понятная ошибка.
31. В редакторе «Перевести»: под текстом появляется перевод (офлайн). Правка распознанного текста обновляет перевод. Печать в поле текста не переключает инструменты.
32. «Буфер» → клик в «Поиск», набрать часть слова: список фильтруется; Enter вставляет первую найденную строку в окно, где был курсор. Esc очищает поиск, второй Esc сворачивает чёлку.
33. Закрепить строку (значок булавки): она поднимается наверх с синей булавкой, не пропадает при «Очистить» и после перезапуска программы (`notch.pins.json` рядом с exe).
34. Окно редактора открывается примерно на 80% экрана, чёлка при этом сворачивается. Окно двигается, разворачивается, есть на панели задач.
35. Инструменты по кнопкам и клавишам P/M/A/R/T/N/B/C, цвета 1–6: кисть, маркер, стрелка (с Shift — ровно по 45°), рамка, текст (клик, печать, Enter; Shift+Enter — новая строка; Esc — отмена), номера шагов 1, 2, 3…, пикселизация, обрезка. Ctrl+Z / Ctrl+Y отменяют и повторяют.
36. «Копировать» (Ctrl+C): в буфере картинка с пометками, вставляется в Paint/Telegram. Новой карточки на полке при этом не появляется.
37. «Сохранить» (Ctrl+S): окно закрывается, на полке сверху новая карточка с пометками (если оригинал был в группе — в той же группе), картинка в буфере. Оригинал не изменился.
38. Закрыть окно редактора крестиком (с пометками или без): закрывается сразу, без вопросов, пометки не сохраняются. Клик по другому скриншоту при открытом редакторе: редактор сразу переключается.
39. Инструмент «Текст»: вместо ползунка толщины на панели выбор размера шрифта (12–100), кнопки A/A и клавиши [ ]. Для кисти, маркера, стрелки, рамки, номеров и размытия — ползунок толщины 1–40 (и [ ]).
40. Ctrl+колесо мыши: масштаб от 5% до 800% вокруг курсора; при сильном увеличении видны чёткие пиксели. Обычное колесо и Shift+колесо прокручивают увеличенную картинку. Пробел + перетаскивание (или средняя кнопка) двигают её. Ctrl+0 или клик по проценту — по размеру окна; Ctrl+= и Ctrl+− — шагами.
41. Перевести компьютер в сон и разбудить (или выключить монитор / заблокировать и разблокировать): чёрного прямоугольника на месте окна чёлки нет. Если он всё же появился — исчезает за 1–5 секунд; в трее есть «Перерисовать окно».
42. Настройки → «Обновления»: видна версия (0.1.N). «Проверить» без интернета → «Нет доступа к GitHub — скачайте через браузер».
43. «Скачать в браузере»: браузер скачивает notch.exe в «Загрузки»; через несколько секунд в чёлке «В «Загрузках» найдена версия …», на шестерёнке синяя точка. «Установить» → «Перезапустить»: запускается новая версия (Настройки показывают её номер), рядом с exe лежит notch.old.exe.
44. «Вернуть предыдущую»: программа перезапускается старой версией.
45. Трей → «Обновления…» открывает чёлку на настройках.
46. Excel: выделить ячейку, нажать «Формат по образцу» (один раз и двойным кликом), применить к другой ячейке — во вкладке «Буфер» ничего нового, перевод не открывается. Ctrl+C по ячейке и «Копировать» в контекстном меню — запись появляется. Двойной Ctrl+C — перевод.
47. Клик по скриншоту на полке: редактор появляется сразу с картинкой, без белой вспышки, поверх всех окон и получает фокус (и когда уже открыт, но перекрыт или свёрнут). Затем клик по другой программе перекрывает редактор, как обычное окно; Alt+Tab возвращает его.
48. Редактор: кнопки «Повернуть влево/вправо» поворачивают картинку вместе с уже нарисованным; после поворота можно рисовать и обрезать; Ctrl+Z отменяет поворот. Сохранённая картинка повёрнута.
49. Скопировать картинку в буфер, в редакторе Ctrl+V (или кнопка «Вставить картинку» → «Из буфера обмена»): картинка появляется по центру, выбран инструмент «Выбор» (V). Перетаскивание двигает, синий уголок меняет размер с сохранением пропорций, крестик или Delete удаляет. «Вставить картинку» → миниатюра с полки — то же.
50. Скопировать один и тот же скриншот дважды (или сохранить из редактора без изменений): на полке одна карточка — самая свежая; если старая была в группе, новая оказывается в той же группе.
51. AutoCAD: скопировать выноску/объекты (Ctrl+C) — на полке ничего нового. Excel: скопировать ячейку (в том числе пустую) — на полке ничего, текст ячейки (если есть) — во вкладке «Буфер». Word: скопировать таблицу — на полке ничего. Win+Shift+S и «Копировать изображение» в браузере — по-прежнему на полке.
52. Скопировать рисунок (картинку) в Word, PowerPoint и Excel — он на полке. Выделить область в Paint и Ctrl+C — на полке.
53. Если какая-то картинка не попала на полку сама: кнопка с «+» в шапке полки кладёт её из буфера.

## Проверки после исправлений по обзору

54. Скопировать в редакторе кода несколько строк с отступами (табы или пробелы) и пару ячеек из Excel. В «Буфере» строки показаны компактно; «Вставить» в Блокнот и обратно в Excel возвращает текст с теми же отступами, а ячейки — по своим столбцам.
55. Положить в «Загрузки» любой чужой exe, переименованный в `notchpad.exe`, и чужой exe с именем `notch (1).exe`: после «Проверить» ни тот ни другой не предлагается как обновление. Настоящий `notch.exe` новее текущего — предлагается (п. 43).
56. На полке 20–30 полноэкранных скриншотов; перезапустить Notch и сделать ещё один: он появляется без задержки, чёлка в это время открывается как обычно. В `cache\shelf` лежит `hashes.json`.
57. Запустить `notch.exe` из папки без права записи (например, из `Program Files`): «Папка программы» открывает `%LOCALAPPDATA%\Notch`; если раньше данные лежали в `%TEMP%\Notch`, закреплённые записи и полка на месте.
58. В Windows включить журнал буфера (Win+V). Скопировать пароль из менеджера паролей, который не пишет в журнал Win+V: в «Буфере» Notch он тоже не появляется.

## Снимок экрана, файлы, клавиатура, мониторы

59. Нажать PrintScreen: экран замирает, курсор — крестик, подсказка по центру. Протянуть рамку: вне её затемнение, над ней размер в пикселях, по краям 8 маркеров, справа инструменты, снизу «Текст · Перевести · Готово · ✕». Первый раз окно появляется с небольшой задержкой, дальше — сразу.
60. Потянуть за маркеры и за саму рамку: размер и положение меняются, рамка не выходит за экран. У края экрана панели инструментов уходят внутрь рамки и остаются видны.
61. Под рамкой та же панель, что в редакторе: кисть, маркер, линия, стрелка, рамка, текст, номер шага, пикселизация, цвета, ползунок толщины (у текста — размер шрифта), отмена/повтор. Каждая пометка остаётся на экране сразу после того, как отпущена кнопка мыши (и текст — после Enter), не дожидаясь выбора другого инструмента. «Двигать область» (V) снова позволяет двигать рамку.
61a. PrintScreen десять раз подряд (с Esc между ними), в том числе после «Готово»: окно появляется сразу, без анимации появления и без кадра от прошлого снимка; Esc убирает его мгновенно, без анимации.
62. «Готово» (или Enter): окно исчезает, область с пометками — на полке и в буфере (вставляется в Paint/Telegram). Без рамки Enter берёт весь экран. Esc закрывает окно, ничего не сохраняя; после него PrintScreen работает снова.
63. «Текст»: окно исчезает, чёлка открывается на «Буфере», распознанный текст сверху и в буфере обмена. «Перевести»: открывается перевод этого текста. На области без текста — понятная ошибка внизу окна, окно не закрывается.
64. Два монитора с разным масштабом: PrintScreen снимает тот, где курсор, окно закрывает ровно его, картинка не размыта и не сдвинута.
65. Настройки → снять «PrintScreen открывает снимок экрана Notch» → Сохранить: PrintScreen снова работает как в Windows. Если PrintScreen уже занят другой программой (ShareX, Lightshot), при включении опции Notch сообщает, что сочетание занято, и настройки не сохраняются.
66. Перетащить файл из Проводника на капсулу и подержать: чёлка раскрывается на «Файлах»; отпустить — файл в списке (имя, папка, размер), на капсуле появился счётчик файлов. То же с тонкой полосой и с несколькими файлами и папкой разом.
67. Из «Файлов» потянуть строку в Проводник, Telegram, письмо: файл попадает туда. «Тащить все» — все разом. Клик открывает файл, папка — показывает в Проводнике, крестик убирает с полки (файл на диске остаётся).
68. Переименовать или удалить файл на диске и открыть вкладку: строка зачёркнута, «нет на месте». Перезапустить Notch: список сохранился.
69. Перетащить скриншот с «Полки» наружу, проведя над чёлкой: вкладка не переключается на «Файлы», в «Файлах» ничего не появляется.
70. Выключить вкладку «Файлы» в настройках: вкладка и счётчик исчезли, удержание кнопки мыши над капсулой её больше не раскрывает.
71. Работая в Блокноте, нажать Ctrl+Alt+B: чёлка открыта на «Буфере», курсор в поиске. Набрать пару букв, стрелками выбрать строку, Enter: текст вставлен в Блокнот, чёлка свернулась. Esc закрывает без вставки и возвращает фокус в Блокнот.
72. Сменить «Клавишу истории» на занятую или на ту же, что у перевода: при сохранении — понятная ошибка, прежние клавиши продолжают работать.
73. Два монитора, включить «Показывать на том мониторе, где курсор»: чёлка появляется на мониторе с курсором через долю секунды; пока она раскрыта или в ней печатают — остаётся на месте. Выключить: возвращается на основной.

## «В проект…» (Papka)

Нужна Papka с хотя бы одним проектом: она пишет список проектов в
`%LOCALAPPDATA%\Papka\projects.json`.

1. PrintScreen → выделить область → поставить стрелку → «В проект…».
   Под панелью инструментов открывается выбор проекта: последний
   выбранный подсвечен, курсор в поле подписи. Буквы в подписи не
   переключают инструменты.
2. Набрать подпись, Enter (или «Отправить»): окно снимка закрывается. Во
   «Входящих» проекта (`<папка объекта>\_Входящие`) — `.png` и `.json`;
   в `.json` подпись, время и `source` с программой и заголовком окна,
   над которым нажат PrintScreen.
3. «Полка»: кнопка с папкой и стрелкой на плитке → «В проект…» →
   «Отправить». Внизу зелёное «Отправлено в «…»».
4. «Буфер»: та же кнопка у строки — уходит текст. «Файлы»: у файла —
   уходит ссылка на файл (сам файл не копируется).
5. Esc в панели закрывает только её, не остров и не окно снимка.
6. Без `projects.json` (Papka не запускалась) панель пишет, что список
   проектов не найден. Проект на недоступном сетевом диске — ошибка с
   именем проекта, снимок не теряется: окно остаётся открытым.
7. В Papka открыть карточку проекта: запись видна во «Входящих».


## Анимации

74. PrintScreen: окно появляется таким же, как живой экран, и за долю секунды темнеет вокруг. Протянуть рамку: панель инструментов поднимается снизу один раз; при рисовании она прячется и возвращается без повторного подъёма.
75. «Готово»: картинка с пометками уменьшается и улетает в чёлку вверху по центру, затемнение и панели уходят, затем счётчик полки в капсуле прокручивается на +1. Пока картинка летит, под ней обычный экран без пометок.
76. Чёлка: полоска под вкладкой переезжает к выбранной, содержимое въезжает со стороны вкладки. При раскрытии сначала вкладки, потом строки или плитки по очереди.
77. «Буфер»: скопировать заново старый текст — строка плавно поднимается наверх, остальные съезжают. Удалить строку — она складывается, соседние подтягиваются. На «Полке» новый скриншот вырастает в свою ячейку.
78. Наведение на строки и кнопки — подсветка проявляется мягко; «Копировать» → галочка «щёлкает».
79. Видео во весь экран (чёлка — тонкая полоса), скопировать текст: полоса на мгновение удлиняется и подсвечивается, но не раскрывается.
80. Перетащить скриншот на другой: тот, над которым держите, чуть увеличивается. Перетащить файл из Проводника на открытую вкладку «Файлы»: наверху пунктирное место «Отпустите — файл ляжет сюда».
81. «Перевод»: новый перевод проявляется, старый бледнеет, пока считается следующий.
82. Включить в Windows «Эффекты анимации: выкл.» — анимации Notch продолжают работать. Снять в настройках Notch «Анимации интерфейса» и сохранить: всё мгновенно во всех окнах (чёлка, редактор, снимок экрана), снимок после «Готово» не летит.
