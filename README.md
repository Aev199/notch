# Notch

Портативная «чёлка» в стиле Dynamic Island для Windows 10/11: Rust + Tauri v2 + React.
Один `notch.exe`, без установщика и без прав администратора.

## Что умеет

| Вкладка | Что делает |
|---|---|
| **Полка** | Каждое изображение из буфера (Win+Shift+S, PrtScr, «Копировать изображение») сохраняется как PNG в `cache\shelf` рядом с exe. Сетка в 4 колонки прокручивается колесом. Одинаковые картинки не дублируются: остаётся только самая свежая копия. На полку попадают скриншоты и скопированные картинки, но не превью скопированных объектов: картинка из Word/PowerPoint/Excel несёт с собой готовый PNG/JPEG/GIF, а ячейки, таблицы и объекты AutoCAD — только превью и свои форматы документа. Графические программы (Paint, Paint.NET, Photoshop, GIMP, Ножницы, ShareX…) всегда идут на полку, CAD-программы (AutoCAD, nanoCAD, BricsCAD, Revit…) — никогда; текст из них записывается как обычно. Если картинка всё же не попала, кнопка «+» на полке забирает её из буфера вручную. Хранятся последние 30 скриншотов (настраивается, до 100), старые удаляются. **Группы**: перетащите скриншот на другой (или на группу), чтобы собрать их вместе. Клик открывает группу, кольцо группы не удаляет, «Очистить» их не трогает. Карточку или целую группу можно **вытащить за край чёлки** в мессенджер, браузер или папку (нативный OLE Drag-and-Drop), скопировать обратно или удалить. **Клик** сразу открывает редактор в отдельном окне: кисть, маркер, стрелка (Shift — по 45°), рамка, текст, номера шагов, пикселизация для скрытия данных, обрезка; 6 цветов, толщина ползунком (1–40), размер шрифта 12–100, поворот на 90°, вставка картинки поверх (Ctrl+V из буфера или с полки — двигать и масштабировать инструментом «Выбор»), отмена/повтор, масштаб Ctrl+колесом (пробел + перетаскивание — сдвиг). Окно редактора поверх всех окон; закрытие без вопросов — несохранённые пометки просто отбрасываются. Там же «Текст» — распознать текст встроенным OCR Windows (офлайн; в рамке обрезки, если она есть) и «Перевести». Распознанный текст можно поправить, перевод обновится. «Сохранить» кладёт результат на полку рядом с оригиналом (в ту же группу) и в буфер, оригинал не меняется. |
| **Буфер** | Последние 30 скопированных текстов (из Excel/Word/PowerPoint — только скопированное клавишами или через контекстное меню, чтобы «Формат по образцу» не засорял историю): лишние пробелы убраны, повторы поднимаются наверх. Клик по строке возвращает её в буфер и сворачивает чёлку. Кнопка **«Вставить»** сразу вставляет текст в поле, где стоит курсор (Ctrl+V через `SendInput`); та же кнопка есть у перевода и у распознанного текста. **Поиск** по истории (регистр и ё/е не важны, Enter вставляет первую найденную строку). **Закреплённые** записи всегда наверху, не вытесняются, не стираются «Очистить» и хранятся в `notch.pins.json`. |
| **Перевод** | RU⇄EN **офлайн**, направление определяется по кириллице. Модели Firefox Translations (Mozilla, движок Bergamot) встроены в exe и работают как WebAssembly, сеть не нужна. По желанию можно включить Google, DeepL или OpenAI-совместимую локальную модель (Ollama, LM Studio). Запуск: **Ctrl+C дважды** в любой программе или горячая клавиша (по умолчанию `Ctrl+Alt+T`): она переводит текст из буфера и ставит каретку в поле ввода. |

* Наведите курсор на капсулу у верхнего края, и она раскроется сразу; уведите курсор, и она свернётся.
  Всё остальное время окно **пропускает клики насквозь**.
* Через 4 секунды бездействия (настраивается) капсула сжимается в **тонкую полосу** 140×5 у края экрана.
  Полоса не ловит клики: вкладки и заголовки окон под ней работают. Чтобы открыть чёлку, задержите
  курсор у самого верхнего края на 0,15 с. Новый скриншот или текст снова показывает капсулу.
* Поверх полноэкранного окна (F11 в браузере, видео, игры без эксклюзивного режима) чёлка всё время
  остаётся полосой. В эксклюзивном полноэкранном режиме DirectX и в режиме презентации она прячется совсем.
* Окно не забирает фокус у активной программы (`WS_EX_NOACTIVATE`), его нет в Alt+Tab
  (`WS_EX_TOOLWINDOW`) и на панели задач. Фокус берётся только при клике в поле ввода;
  Esc или уход курсора возвращают фокус туда, где он был.
* Содержимое, которое менеджеры паролей помечают как секретное
  (`ExcludeClipboardContentFromMonitorProcessing`), не записывается.
* Иконка в трее: открыть, перевести буфер, папка программы, выход.

## Портативность

Всё лежит рядом с `notch.exe`:

```
notch.exe
notch.settings.json     настройки (сервис перевода, ключи, горячая клавиша…)
notch.history.json      история текста — только если включено в настройках (по умолчанию выключено)
notch.pins.json         закреплённые записи буфера
cache\shelf\            скриншоты полки, их миниатюры и groups.json (какой скриншот в какой группе)
```

Если папка exe недоступна для записи (например, `Program Files`), данные хранятся в `%TEMP%\Notch`.
Автозапуск (переключатель в настройках) прописывает exe в
`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`, права администратора не нужны.

Нужен WebView2 Runtime. В Windows 10/11 он обычно уже установлен вместе с Edge.

## Устройство

```
crates/core/        чистая логика без Tauri, с тестами:
  hover.rs          конечный автомат: полоса / капсула / открыто, сквозной клик
  text_history.rs   кольцевой буфер текстов, очистка, дубликаты
  shelf.rs          PNG + миниатюры, кольцо с удалением файлов, группы (индекс groups.json)
  translate.rs      направление RU/EN, запросы и разбор ответов Google/DeepL/LLM
  ocr.rs            подготовка скриншота к OCR (масштаб, BGRA)
  settings.rs       JSON рядом с exe, атомарная запись
src-tauri/src/
  overlay.rs        опрос GetCursorPos (16 мс у верхнего края, 50 мс в остальное время), стили окна, полноэкранный режим, позиция
  models.rs         встроенные офлайн-модели (models/, gzip)
  ocr.rs            распознавание текста через Windows.Media.Ocr (WinRT)
  clip.rs           слушатель WM_CLIPBOARDUPDATE (clipboard-master), arboard, двойной Ctrl+C
  net.rs            reqwest (SChannel TLS)
  win.rs            Win32: стили окна, фокус, реестр, единственный экземпляр
  state.rs, lib.rs  состояние, команды, трей, горячая клавиша
src/                React + Motion: остров с пружинной анимацией размеров и скруглений, три вкладки и настройки
  lib/offline.ts    офлайн-переводчик Bergamot (WebAssembly в воркере), модели берутся из exe по IPC
  editor/           редактор скриншотов (отдельное окно, тот же бандл с ?editor=<id>): модель фигур и отрисовка на canvas
```

Почему сквозной клик устроен именно так: пока окно пропускает клики, страница не получает событий мыши,
поэтому наведение отслеживает Rust. Как только курсор попал на капсулу, окно начинает ловить мышь и
раскрывается. Если курсор пробыл вне острова 350 мс, окно сворачивается и снова пропускает клики.
Пока зажата кнопка мыши, идёт перетаскивание или открыто поле ввода, окно не сворачивается.

Стили `WS_EX_TRANSPARENT | WS_EX_LAYERED` (сквозной клик) и `WS_EX_TOOLWINDOW` выставляет только поток
наведения, на каждом такте. Tauri переписывает расширенные стили целиком, когда меняет что-то своё
(например, `focusable` для `WS_EX_NOACTIVATE`). Такой сбой исправляется на следующем такте, а гонки
двух потоков за один стиль больше нет: раньше из-за неё кнопки иногда не нажимались.

## Обновления

Схема та же, что в Papka:

- Раз в сутки (и по кнопке «Проверить» в настройках) Notch смотрит выпуски GitHub; `notch.exe`
  сверяется с SHA-256 из `latest.json`.
- Если программе закрыт интернет, «Скачать в браузере» открывает
  `releases/latest/download/notch.exe` в браузере, а Notch 20 минут следит за «Загрузками»
  (и проверяет их раз в час): найденный `notch*.exe` новее текущего предлагается установить
  (версия читается из свойств файла).
- Установка: работающий `notch.exe` переименовывается в `notch.old.exe`, новый встаёт на его место,
  при ошибке всё возвращается. «Перезапустить» запускает новую версию; «Вернуть предыдущую» меняет
  файлы местами.
- Версия = `0.1.<номер сборки>`; локальные сборки (`0.1.0`) сами не проверяют обновления.

## Сборка

Windows, Rust stable, Node 22:

```
npm ci
npx tauri build
```

Готовый файл: `src-tauri/target/release/notch.exe` (около 55 МБ, почти всё занимают модели перевода). Его же собирает GitHub Actions
(`.github/workflows/windows.yml`, артефакт `notch-portable-N`). Чтобы выпустить релиз,
запустите workflow вручную с `release: true`.

Проверки из Linux:

```
cargo test --manifest-path crates/core/Cargo.toml
npm run build
cd src-tauri && cargo check --target x86_64-pc-windows-gnu   # нужен mingw-w64
```

## Происхождение

Основа взята из [PILLAR](https://github.com/WarPirate/pillar-dynamic-island-for-windows) (MIT):
прозрачная сцена поверх всех окон, позиционирование у верхнего края, пружинная анимация на Motion.
Модули PILLAR (системный монитор, медиаплеер, громкость, уведомления, ИИ-чат Prism) убраны,
каркас переписан под три вкладки. Перетаскивание наружу сделано на
[tauri-plugin-drag](https://github.com/crabnebula-dev/tauri-plugin-drag) от CrabNebula.
Офлайн-перевод сделан на [bergamot-translator](https://github.com/browsermt/bergamot-translator)
(MPL-2.0) с моделями Firefox Translations от Mozilla (MPL-2.0); откуда взяты модели и их контрольные
суммы, описано в `src-tauri/models/README.md`.
